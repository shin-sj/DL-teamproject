🎭 Stereotype 깨기 — 모델한테 일부러 헷갈리는 사람을 보여주면?

"60대 한국 남자"라고 하면 트로트, 등산, 막걸리가 떠오르잖아요. 그런데 만약 그 사람이 사실은 매일 PC방에서 게임만 한다면? 모델은 이 사람을 어떻게 분류할까요? 한국 사회의 고정관념(stereotype)과 일부러 안 맞는 사람 6명을 만들어서 모델에게 보여줬어요.

🤔1. 어떤 실험인가

우리 모델한테 "한국 사회 고정관념과 정반대인 사람"들을 보여주고 어떻게 답하는지 본 거예요.

예를 들어 이런 사람들

CASE 1
👴 65세 김철수 어르신
"매일 PC방에서 6시간씩 e스포츠 게임을 하시고, 디스코드로 길드원들과 활발히 교류한다."
→ 평범한 60대처럼 트로트 듣고 등산 가는 게 아니라 20대 게이머처럼 행동하는 60대. 모델이 이 사람을 잘 분류할까?
CASE 2
🧁 민호씨 (30대 남성)
"30대 가정주부로 매일 아이 셋을 등원시키고 베이킹과 살림에 매진한다."
→ 보통 stereotype상 "가정주부·베이킹·살림"은 여성과 연결되잖아요. 그런데 분명히 "민호씨"라고 남자 이름이 있는데, 모델은 누구로 분류할까?

이런 식으로 stereotype과 어긋나는 사람 6명을 만들어 모델에 넣어봤어요.

💡2. 왜 했나 — 평균 점수만 보면 모르는 게 있어서

지금까지의 실험은 "평균적으로 모델이 얼마나 잘 맞춰?" 같은 거였어요. 예를 들어:

"지명 다 가렸을 때도 모델이 광역시도를 74% 맞춤" → "와 stereotype이 진짜 많구나"

이건 의미 있지만 한계가 있어요. "모델이 정확히 어디서 헷갈리는지", "어떤 단어에 약한지" 같은 디테일은 안 보여요. 그래서:

💡 아이디어: 일부러 모델을 헷갈리게 하는 "함정 페르소나"를 만들어서 모델이 어떻게 반응하는지 보자!

→ "60대인데 게이머", "남자인데 가정주부" 같은 케이스를 넣고 모델이 명시된 정보(나이·이름)를 따라가는지, 아니면 stereotype(게임·살림)에 끌려가는지 본다.

왜 이게 좋냐면

① 모델 편향이 분명히 드러남
평범한 페르소나에서는 stereotype 따라가도 정답이라 안 보이는데, 충돌 페르소나에서는 stereotype에 끌리면 틀린 답으로 직접 보임.
② 발표 때 라이브 시연 가능
숫자(74%) 보여주는 것보다 "이 사람 한 명 보여줬더니 모델이 이렇게 잘못 답함" 시연이 훨씬 임팩트 큼.

🧪3. 어떻게 했나 — 6명의 함정 페르소나

한국 사회에 흔한 stereotype 4가지(성별, 나이, 지역, 라이프스타일)를 각각 깨는 사람 6명을 만들었어요.

🎮 60대 PC방 게이머
"65세 김철수 어르신, e스포츠 6시간/일"
👵 보통 60대 ≠ 🎮 PC방 게이머
⚽ 축구광 30대 여성
"30세 박지영씨, EPL 광팬, 풋살 주장"
👩 보통 여성 ≠ ⚽ 풋살·EPL
🎤 20대 트로트 광팬
"26세 김지수씨, 임영웅 열성팬"
🧑 보통 20대 ≠ 🎤 트로트·임영웅
🏙️ 서울 강남 어부
"서울 강남 박여사, 갯벌·꼬막무침"
🏢 서울 ≠ 🌊 갯벌·꼬막
🧁 남성 가정주부
"민호씨, 30대 가정주부, 베이킹·살림"
👨 보통 남성 ≠ 🧁 가정주부·베이킹
🌾 70대 여성 게이머
"75세 이여사, 배틀그라운드, 트위치"
👵 보통 70대 ≠ 🎮 게이밍

각 페르소나를 두 모델(TextCNN, Hybrid)에 넣고 "성별이 뭐다, 나이가 몇 살대다, 어디 산다, 어떤 라이프스타일이다" 4가지를 예측하게 했어요.

📊4. 결과 — 모델별로 완전히 다르게 답함

먼저 핵심부터:

TL;DR
✓ TextCNN은 6명 다 성별 맞춤 (잘 버팀)
✗ Hybrid는 6명 중 3명 성별 오판 (stereotype에 휘둘림)

→ 평균 점수로 보면 두 모델 비슷한데, 충돌 페르소나로 시험하면 완전히 다른 성격이라는 게 드러남.

전체 결과 표

페르소나 실제 TextCNN Hybrid
성별나이 성별나이
🎮 60대 PC방 게이머 남 / 60s 남 (51%) 60s ✓ 여 ✗ 60s ✓
⚽ 축구광 30대 여성 여 / 30s 여 ✓ 30s ✓ 여 ✓ 30s ✓
🎤 20대 트로트 광팬 여 / 20s 여 ✓ 20s ✓ 남 ✗ 20s ✓

빨간 칸이 모델이 stereotype에 끌려 틀린 답을 한 곳이에요. Hybrid한테 빨간 칸이 4개나 있어요.

🔬5. 인상적인 케이스 — 사례로 보기

📌 케이스 A — "민호씨, 30대 가정주부" (가장 인상적)

함정 페르소나
"민호씨는 30대 가정주부로 매일 아이 셋을 등원시키고 베이킹과 살림에 매진한다. 요리 블로그를 운영한다..."

"민호씨"라고 이름까지 있고 30대 가정주부라고 했으니 분명히 남성이죠. 그런데:

TextCNN → 남자 ✓ (82% 확신)
👍 잘 맞춤. 이름 "민호"를 따라간 듯.
Hybrid → 여자 ✗ (90% 확신)
👎 90%로 강하게 잘못 답함. "베이킹·살림" stereotype에 압도됨.
😲 사람이라면? "민호씨면 당연히 남자지" 라고 자연스럽게 알 것 같은데, 모델은 "베이킹"·"살림" 단어 보고 "여자다!" 라고 90%로 확신해버려요. 이게 stereotype이 모델 안에 얼마나 깊이 박혀있는지 보여주는 케이스예요.

📌 케이스 B — "65세 어르신, PC방 게이머" (가장 헷갈림)

함정 페르소나
"65세 김철수 어르신은 매일 PC방에서 6시간씩 e스포츠 게임을 하시고, 디스코드로 길드원들과 활발히 교류한다..."

분명히 65세 김철수 "어르신"이니까 남성이죠. 그런데:

TextCNN → 남자 ✓ (51%)
🤔 거의 동전던지기 수준. "남자다" 답은 맞췄지만 확신 거의 없음.
Hybrid → 여자 ✗ (97% 확신)
👎 또 여자라고 거의 100%로 잘못 답함.
🎯 TextCNN의 51%가 흥미로워요 TextCNN이 "남자 51%, 여자 49%"라고 답한 건 거의 동전던지기 수준. 모델이 "어르신·김철수"(남성 신호) vs "PC방·게임"(stereotype은 젊은 남성/모호) 사이에서 갈피를 못 잡고 있다는 거예요.

→ 모델이 헷갈릴 때 "헷갈린다"고 정직하게 표현하는 게 오히려 좋은 점. Hybrid는 헷갈려도 97% 확신으로 잘못 답하는데, TextCNN은 51%로 "잘 모르겠다"고 알려줘요.

📌 케이스 C — "트로트 광팬 → 모델이 경상북도라고 답함" (가장 놀라움)

함정 페르소나
"26세 김지수씨는 트로트 가수 임영웅의 열성팬이다. 매주 트로트 콘서트를 다니며..."
⚠️ 텍스트에 지역 단어가 단 하나도 없어요. 서울, 부산, 어디라고 한 마디도 안 했어요.

그런데 Hybrid 모델은 이 사람의 거주 지역을 경상북도라고 예측했어요.

🤯 왜 경상북도? 임영웅이 경상북도 포항 출신이거든요. 모델이 학습하면서 "임영웅 → 포항 → 경북"이라는 stereotype을 자동으로 외운 거예요. 이 사람이 임영웅 팬이라는 이유 하나로 "경북 사람일거야" 라고 추론한 거죠.

→ 텍스트에 지역 단어가 한 글자도 없는데 가수 이름 하나만으로 거주지를 추론하다니, stereotype이 모델 안에 얼마나 깊이 박혔는지 보여주는 가장 강력한 사례.

📌 케이스 D — "75세 여성 게이머 → 50대라고 함" (나이까지 흔들림)

함정 페르소나
"75세 이여사는 매일 PC방에서 배틀그라운드를 플레이하고, 트위치에서 게이밍 방송을 자주 본다..."

"75세"라고 분명히 적혀있는데, Hybrid는 이 사람을 50대로 92% 확신으로 예측. TextCNN은 70+로 정확히 맞춤.

🎮 게임 = 젊음 stereotype "PC방·배틀그라운드·트위치" 같은 게이밍 키워드가 모델 안에서 "젊은 사람" 신호를 너무 강하게 활성화시켜요. 그래서 텍스트에 "75세"라는 명백한 숫자가 있는데도 "에이 이 사람 50대일거야" 라고 답해버린 거예요.

→ 보통 나이 task는 텍스트에 적힌 숫자만 보면 거의 100% 맞춰요(다른 5 케이스 다 100%). 그런데 이 케이스만 무너진 게 stereotype의 위력을 보여주는 증거.

🤷6. 왜 Hybrid가 더 휘둘리나

같은 데이터로 같이 학습했는데 왜 Hybrid만 stereotype에 약할까? 모델 구조 때문이에요.

TextCNN — "가장 강한 신호 1개"만 채택

TextCNN은 문장을 훑으면서 가장 임팩트 강한 키워드 1개를 골라서 답해요. "민호씨"라는 강한 단서 하나가 있으면, "베이킹·살림"이 여러 개 있어도 "민호씨"가 가장 강하면 그것만 따라감.

→ 강한 단서 하나에 집중하는 보수적 성격.
Hybrid — 모든 신호를 평균

Hybrid는 문장 전체의 평균적인 분위기를 따라요. "베이킹·살림·요리·뜨개질" 같이 stereotype 키워드가 4-5개 있으면 평균이 "여성"쪽으로 기울어버림. 명시적 단서 "민호씨" 하나는 평균에 묻혀버려요.

→ 많은 신호들의 평균에 끌리는 성격 → stereotype에 약함.
🍱 비유로 말하면 TextCNN은 단호한 친구 — "민호라잖아, 그럼 남자지" 한 마디로 결정.
Hybrid는 분위기 보는 친구 — "근데 베이킹하고 살림하고 뜨개질하고... 음~ 여자 같은데?" 라며 키워드 분위기에 끌림.

두 친구 다 평균 시험 점수는 비슷한데, 이상한 사람이 나타나면 반응이 완전 달라요.

✨7. 한 줄 정리

📌 우리가 발견한 것
  • stereotype과 어긋나는 사람 6명을 모델에게 보여줬더니
  • TextCNN은 6/6 성별 정답, 잘 버텼어요
  • Hybrid는 6명 중 3명 성별 오판, stereotype에 끌렸어요
  • 평균 점수표(둘 다 75점대)에서는 안 보이던 차이가 충돌 페르소나에서 분명히 드러남
💎 발표 임팩트가 큰 이유 "Masked+Geo 조건에서 광역시도 74%"라는 숫자보다, "임영웅 팬이라는 이유로 경상북도라고 답함" 같은 구체적 사례가 훨씬 인상적이에요. 청중이 한 번에 이해하고 기억해요.
🎯 결론 LLM이 만든 페르소나는 한국 사회 stereotype을 깊이 인코딩하고 있고, 그걸 학습한 우리 모델(특히 Hybrid)은 "민호씨"라는 명백한 남성 이름이 있어도 베이킹 단어 보고 여자라고 90%로 확신해버려요.

→ 평균 점수표는 모델 성능만 알려주지만, 충돌 페르소나는 모델의 "성격"과 "편향의 작동 방식"까지 노출해요.
